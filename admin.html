Conectar Mercado Livre

Autorize a conta Mercado Livre vinculada à aplicação OFERTIX. A autorização usa PKCE e senha administrativa; nenhum token aparece no navegador.

Autorizar Mercado Livre ↗

Depois de autorizar, volte para esta aba e toque em Atualizar painel. Esta versão de testes usa armazenamento temporário no Render Free.

Importar produtos populares

Informe uma categoria final do Mercado Livre. Se usar uma categoria ampla, como MLB1051, toque em Buscar subcategorias e escolha uma opção até chegar à categoria final. A verificação só publica promoções com desconto confirmado e link oficial de afiliado.

Escolha uma categoria final. O resultado da importação aparecerá aqui.

Para importar categorias automaticamente durante a execução, configure OFERTIX_CATEGORIES no Render, separando os IDs por vírgulas. No Render gratuito, o processo pode hibernar e não executar a tarefa no horário.

Cadastrar oferta pelo link de afiliado

Gere o link para um produto específico na Central ou Barra de Afiliados do Mercado Livre. Cole somente o link abaixo. O OFERTIX tentará identificar o anúncio automaticamente, sem buscar categorias.

Use esta opção se o link abrir uma página de catálogo sem ID de anúncio de vendedor.

Opções avançadas — informar ID manualmente

Abra se o link levar a uma página de catálogo ou não contiver um anúncio identificável. Informe o ID de anúncio de vendedor, não o ID de produto de catálogo.

Cole seu link e toque em Identificar e verificar oferta. Se não for possível localizar o ID, o sistema informará o motivo.

Só são publicadas ofertas cuja API confirme um desconto de pelo menos 10%. Caso o link aponte para catálogo, nenhuma publicação será inventada. O domínio do link, sozinho, não comprova a atribuição de comissão.

Diagnóstico de anúncio e preço — V11

Teste separadamente os dados de um anúncio e o preço. Use um ID MLB de vendedor. Esta ferramenta é apenas de diagnóstico: não cadastra, publica ou altera ofertas.

Informe o ID do anúncio para verificar os dois endpoints oficiais.

HTTP 403 pode indicar falta de permissão. Nenhum token, chave secreta ou resposta bruta da API aparece neste painel. Um preço acessível não é suficiente para autorizar a publicação.
